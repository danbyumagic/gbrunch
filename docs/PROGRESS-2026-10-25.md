# HP Envy: simpler installation and Linux VM investigation

AMD work is paused. No HP disk or Windows boot configuration was changed.

## Completed in this session

- Restored and verified the pinned official Lenovo Ruby recovery ZIP/raw image in private cloud storage. The previous cloud session's temporary build files were absent after restart.
- Created a portable file-only single-partition storage probe.
- Booted it twice under QEMU TCG with both Debian's kernel and Google's unchanged Ruby kernel; writes persisted in a nested dummy data partition.
- Confirmed a missing image refuses to boot and readback preserves the dummy system partition bytes. Primary/backup outer and nested GPT checksums validated.
- Inspected the original kernel config and Google virtualization APEX/terminal package. Intel KVM, host-vsock and tun are compiled in; this alone does not establish runtime VM availability.
- Added bounded, read-only AVF/terminal diagnostics to the existing compatibility logger and extended its failure-preservation checks.
- Added a Windows read-only installation-readiness report script and documented the Windows system-disk/WSL limitation.
